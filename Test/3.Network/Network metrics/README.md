# Network Metrics Analysis

This directory focuses on calculating and validating complex network metrics (such as centrality, degree, and betweenness) derived directly from the posterior samples generated by **BayesForge (BF)**.

## Requirements

The required Python packages are listed in `requirements.txt`. Install them using:

```bash
pip install -r requirements.txt
```

*(Note: `jupyter` is required if you wish to run the interactive notebook.)*

## How to Run the Models

You can execute the network metrics pipeline in two ways:

1. **Via Python Script**:
   ```bash
   python network_metrics.py
   ```
2. **Via Jupyter Notebook**:
   Open and run the `10.Network metrics.ipynb` notebook for an interactive, step-by-step exploration of the metric distributions.

## Outputs

The scripts produce the following outputs:
- Log files (`log.txt`) documenting the execution steps and calculated metric summaries.
- In the notebook, visual plots of the network metric distributions (such as eigenvector centrality) computed over the posterior graph samples.
