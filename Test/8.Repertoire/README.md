# Repertoire Size Estimation Models

This directory contains the testing and benchmarking pipeline for individual signal repertoire size estimation models. It implements the probabilistic approach established by McElreath et al. for estimating full repertoire size from unbalanced sampling data.

## Folder Structure

- `data/`: Contains all the raw and generated data matrices (e.g. `data_Y.csv`, `stan_data.json`) and ground truth targets. 
- `scripts/`: Contains the Python implementation of the models using **BayesForge**, the Stan benchmarks, and the comparison scripts. 
- `results/`: Contains the output comparison plots, moment comparisons, and execution logs. 
- `legacy/`: Contains the original R scripts, Stan models, and inputs provided from the original published methodology (e.g., `cg_vocal_repertoires`).

## Requirements

The required Python packages are listed in `requirements.txt`. Install them using:

``` bash
pip install -r requirements.txt
```

*(Note: You must also have CmdStan installed for `cmdstanpy` to function for the reference sampling).*

## How to Run the Models

A `run_all.py` script is provided at the root to automate the comparison.

To run the full pipeline:

``` bash
python3 run_all.py
```

This will trigger the scripts inside the `scripts/` directory to: 1. Run `benchmark.py`: Fit the model using both BayesForge and Stan, comparing timing performance. 2. Run `compare_moments_p.py`: Compare the posterior moments between the two backends. 3. Run `compare_summary.py`: Produce visual summary comparisons of the fits.

## Outputs

All outputs from the pipeline are deposited in the `results/` folder: - `run_all_log.txt`: Standard out and timing results from the execution. - `comparison_plot.png` & `debug_plot*.png`: Visual diagnostic plots generated by the comparison scripts.
