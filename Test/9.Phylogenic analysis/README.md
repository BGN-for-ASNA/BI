# Phylogenetic Multilevel Models Analysis

This directory contains tests for estimating Phylogenetic Multilevel Models using **BayesForge (BF)**. It compares the performance and posterior estimates of BayesForge against `brms` across 5 different model structures.

## Included Models

1.  **Model_1_Simple**: Continuous response with a simple phylogenetic effect.
2.  **Model_2_Poisson**: Count response with a Poisson likelihood and a phylogenetic effect.
3.  **Model_3_Repeated**: Repeated measurements per species.
4.  **Model_4_Meta**: Meta-analysis structure (incorporating measurement error).
5.  **Model_5_Slopes**: Varying slopes per phylogenetic group.

## Requirements

The required Python packages are listed in `requirements.txt`. You can install them using:

``` bash
pip install -r requirements.txt
```

*(Note: To run the baseline comparison scripts, you must also have R installed with the `brms` package.)*

## How to Run the Models

A `run_all.py` script is provided to automate the execution of all models.

To run all 5 models sequentially:

``` bash
python3 run_all.py
```

This script will automatically navigate into each subdirectory, execute the BayesForge fitting script (`fit_BF_*.py`), and subsequently run the R comparison script (`compare_*.R`) to generate diagnostic plots and metrics. You can track its progress in `run_all_log.txt`.

## Outputs

For each model subdirectory, the test pipeline produces the following outputs:

-   `BF_post_*.csv`: The posterior samples generated by BayesForge.
-   `comparison_*.csv`: A quantitative summary comparing the posterior means and standard deviations between BayesForge and `brms`.
-   `density_comparison.png`: A visual density plot overlaying the posteriors from BayesForge and `brms` for key parameters.
-   `run_log.txt` / `log.txt`: Console outputs and potential sampler warnings.
