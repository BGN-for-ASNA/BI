\section*{Data Availability Statement}
All implementations of \textit{BI} are publicly available through their respective
GitHub repositories for \href{https://github.com/BGN-for-ASNA/BI}{Python},
\href{https://github.com/BGN-for-ASNA/BIR}{R}, and
\href{https://github.com/BGN-for-ASNA/BIJ}{Julia}. In addition, each implementation
can be installed via the standard package repositories of the corresponding
programming languages: 
\href{https://pypi.org/project/BayesInference/}{pip} for the Python version, \href{https://cran.r-project.org/web/packages/BayesianInference/index.html}{CRAN} for the R
version, and the \href{https://github.com/JuliaRegistries/General/tree/master/P/PyBayesianInference}{Julia package registry} for the Julia version. Comprehensive documentation, including installation instructions, tutorials, and
extended examples, are available on the official project website:
\href{https://s-sosa.com/BI}{https://s-sosa.com/BI}.
